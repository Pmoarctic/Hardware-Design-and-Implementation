# Interrupt-driven assembly stopwatch

This stopwatch starts, pauses, resumes, records up to 10 laps, and resets. The program is written in S2 assembly in `stopwatch.txt`. Both the cumulative timestamp and the duration since the previous lap are stored in simulated RAM.

## 1. Open PowerShell in this folder

```powershell
Set-Location 'E:\CEDT\Hardware Design and Implementation\mid-project\stopwatch'
python --version
```

Python 3 runs the course tools. The display uses Tkinter, which is available in the checked Python installation. No pip packages are required. If using another installation, check `python -m tkinter` (close the small test window afterward).

## 2. Compile / assemble the program

Assembly source is **assembled** into object code; there is no RZ compilation step.

```powershell
python build.py
```

Expected message: `Built stopwatch.obj and stopwatch.lis using the copied course tools.`

The build calls the unchanged assembler and listing utility in `../tools/`. It produces:

- `stopwatch.obj`: instructions loaded into the simulated CPU.
- `stopwatch.lis`: assembly listing with instruction addresses.
- `stopwatch-f.txt`: intermediate file generated by the course assembler.
- `assemble.log`, `listing.log`: diagnostics.

Rebuild after every change to `stopwatch.txt`. The graphical launcher rejects an object file older than the assembly source.

Equivalent manual commands, run from this folder:

```powershell
'stopwatch.txt' | python ../tools/as21.py
'stopwatch.txt' | python ../tools/lister.py
```

Use the plain filename `stopwatch.txt` at the assembler prompt: the original tool uses the first dot in its input path to derive output names.

## 3. Run the interactive simulation

```powershell
python simulator.py
```

Keep the stopwatch window focused when using keyboard shortcuts.

| Button / key | Behavior |
|---|---|
| Start / Pause / `S` | Start from zero, pause, or resume from the paused value. |
| Save lap / `L` | Save the current elapsed time while running; timing continues. |
| Reset / `R` | Immediately stop, set time to zero, and clear all recorded laps. |
| `Q` / close window | Exit. The simulated RAM and lap history are discarded. |

Step-by-step practice:

1. Press `S`; the elapsed display starts advancing.
2. Press `L` whenever you want a lap. A row appears while the clock continues.
3. Press `L` again. The new duration is the difference between this timestamp and the previous one.
4. Press `S` to pause. Wait and observe that elapsed time does not increase.
5. Press `S` again to resume; paused time is excluded.
6. Press `R` to clear the session and stop.

Example: captures at `00:03.20` and `00:07.85` produce durations `00:03.20` and `00:04.65`. Actual demonstration values depend on when you press the buttons.

Captures are limited to 10 per session. An eleventh request shows a full-memory message and preserves earlier records; the clock continues. A lap request while paused is ignored. Two requests within the same tick may have equal timestamps and a zero duration. Reset clears all slots. Laps are retained in simulated RAM only, not across closing the window.

## 4. How assembly and the simulator cooperate

`simulator.py` is a button/display adapter. It loads `../tools/sim21.py` without its final interactive `main()` call, then runs the original instruction decoder, timer device, interrupt dispatcher and `reti` implementation. Original tool files are unchanged. The adapter suppresses the course engine's repetitive console messages and replaces its blocking monitor with a graphical display.

- Every 1,000 CPU cycles, the course timer raises INT0. Assembly increments `elapsed` only if `running` is 1.
- A button writes a command number into mailbox address 1104 and raises interrupt request 2. It does not write stopwatch results.
- The CPU saves the return address in r31 and jumps to the ISR address in its vector table. The ISR saves r0-r15 on the stack, handles the command, restores registers and executes `reti`.
- Assembly handles start/pause, copying timestamps into memory, subtracting the previous timestamp, capacity checking and reset.
- The main loop counts its passes and waits with `wfi`. The counter demonstrates that execution returns to normal work after interrupt service.
- The window reads RAM and formats values. Its event log is generated after the button ISR returns.

Timer IRQ0 has higher priority than button IRQ2 when both are pending. Interrupt nesting is disabled during ISR execution. A lap captures the elapsed value when its ISR executes, with tick resolution and a small interrupt-service delay.

The adapter queues up to 32 pending button requests and delivers them individually. It runs a continuing simulation rather than the stock monitor's 4,000-cycle bounded `g` command.

### Time units

One tick is displayed as 0.01 seconds. The launcher targets 100,000 simulated cycles per real second, but the timer is fundamentally simulated. Scheduling, heavy load, or suspending the window can make it lag real time. This is an interrupt demonstration, not a calibrated physical stopwatch. Start and resume use the free-running timer phase, so their first increment can occur within one tick.

### Memory map

| Address | Meaning |
|---|---|
| 1000 / 1002 | Timer / button ISR vector |
| 1100 | Elapsed ticks |
| 1101 | Running: 0 or 1 |
| 1102 | Saved lap count: 0 through 10 |
| 1103 | Previous lap timestamp |
| 1104 | Command: 1 toggle, 2 lap, 3 reset; cleared by ISR |
| 1105 | Result code (documented in assembly) |
| 1106 | Initialization complete |
| 1107 | Main-loop passes |
| 1200-1209 | Cumulative lap timestamps |
| 1220-1229 | Individual lap durations |
| 3000 | Initial stack pointer; stack grows upward |

Enter `stopwatch.obj` at `object file:`. The following is a bounded debugger demonstration; monitor commands themselves do not advance simulated time.

Find the address of `main_loop` in the symbol list at the end of `stopwatch.obj`, then enter `b ADDRESS` (replace ADDRESS with that number) followed by `g` to stop before its first instruction. Use `t` to single-step. `d 1100 8` shows state and `d 1200 10` shows lap timestamps. `q` quits.
