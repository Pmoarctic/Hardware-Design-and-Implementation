หลักการที่ใช้

แบ่งหน้าที่อย่างไร?

Python: จำลอง CPU, Timer, การส่งคำขอ Interrupt และ GUI โดย GUI อ่าน RAM มาแสดงผล

S2 Assembly: ตรวจสถานะ เพิ่มเวลาสะสม เริ่ม/หยุด บันทึกรอบ คำนวณระยะรอบ ตรวจความจุ และรีเซ็ต

INT0: Timer ขอ Interrupt ทุก 1,000 simulated cycles ถ้า running = 1 จึงเพิ่ม elapsed หนึ่ง Tick

INT2: ปุ่มส่งคำสั่งผ่าน RAM[1104]: 1 = Start/Pause, 2 = Lap, 3 = Reset

รีจิสเตอร์แต่ละตัวทำอะไร?

  • PC: ตำแหน่งคำสั่ง ไม่ใช่หนึ่งใน r0–r31
  • r31: CPU เก็บ PC ที่จะกลับเมื่อรับ Interrupt
  • r29: Stack Pointer เริ่มที่ 3000
  • r0–r15: ISR เก็บก่อนใช้และคืนค่าตอนจบ
  • r1: ใช้อ่าน command / สถานะ / เวลา / ผลลัพธ์ตามช่วงคำสั่ง
  • r2: ใช้เปรียบเทียบคำสั่ง จำนวนรอบ และดัชนีวนลูป
  • r3: ใช้ผลเปรียบเทียบและเวลารอบก่อนหน้า
  • r4: ใช้เก็บผลต่างเวลาของรอบ
ขั้นตอนสิ่งที่เกิดขึ้นจุดที่ควรชี้
เข้า InterruptCPU เก็บ return PC ใน r31 แล้วอ่านตำแหน่ง ISR จาก vector RAM[1002]PC เปลี่ยนไปที่ button ISR; ปิดการรับ Interrupt ซ้อน
trap r29 #15เก็บ r0–r15 จำนวน 16 ค่า ลง Stackr29: 3000 → 3016
จัดการปุ่มอ่าน command แล้วเลือก Start/Pause, Lap หรือ Resetr1–r4 และ RAM เปลี่ยนตามคำสั่งจริง
trap r29 #16คืนค่า r0–r15 จาก Stackr29: 3016 → 3000; ค่ารีจิสเตอร์กลับเหมือนก่อน ISR
retiตั้ง PC จาก r31 และเปิดการรับ Interrupt อีกครั้งกลับไปทำงานต่อ; หากมีคำขอรออยู่ CPU อาจรับต่อทันที

r31 ไม่ได้คืนค่าเดิมแบบ r0–r15 เพราะเป็นที่เก็บตำแหน่งกลับของ Interrupt ครั้งนี้ ส่วน INT_ENABLE ที่แสดงคือสถานะรับ Interrupt ภายในตัวจำลอง ไม่ใช่รีจิสเตอร์ r ตัวหนึ่ง

ตัวเลขสถานะต้องอ่านคู่กับชื่อตัวแปร

ตัวเลขเดียวกันอาจมีคนละความหมาย เช่น command = 2 คือขอบันทึก Lap แต่ result = 2 คือหยุดชั่วคราว และค่าจากการเปรียบเทียบ 1 หมายถึง TRUE ไม่ได้หมายถึงกำลังจับเวลาเสมอไป

ตัวแปร / สถานะความหมายของตัวเลข
running0 = ไม่สะสมเวลา (ยังไม่เริ่ม / Pause / Reset), 1 = กำลังจับเวลา ไม่มีรหัสแยกสำหรับ Pause และ Reset
command0 = ไม่มีคำสั่งค้าง, 1 = Start/Pause, 2 = Lap, 3 = Reset
result0 = ยังไม่มีผลลัพธ์, 1 = เริ่ม/ทำงานต่อ, 2 = Pause, 3 = บันทึก Lap แล้ว, 4 = เต็ม 10 รอบ, 5 = บันทึกไม่ได้เพราะหยุดอยู่, 6 = Reset แล้ว, 7 = ไม่รู้จักคำสั่ง
ready0 = ยังเริ่มต้นไม่เสร็จ, 1 = เริ่มต้นระบบเสร็จแล้ว
ผลเปรียบเทียบ eq / lt0 = FALSE (เท็จ), 1 = TRUE (จริง) ใช้เลือกว่าจะกระโดดไปทำส่วนใด
INT_ENABLE0 = ปิดรับ Interrupt ซ้อน, 1 = เปิดรับ Interrupt โดยยังต้องพิจารณา mask และคำขอที่รออยู่
